# ARI TEN — Private Pool Villa · Ari, Bangkok

โฆษณาบ้าน Private Pool Villa ซอยอารีย์ (10 ห้องนอน 3 ชั้น + สระว่ายน้ำ)

- `index.html` — หน้าเว็บหลัก (อ้างอิงไฟล์ใน `assets/`)
- `assets_src/*.b64` — รูป/เพลงในรูปแบบ base64 text; Netlify build จะ decode กลับเป็นไฟล์จริงใน `assets/` อัตโนมัติ (ดู `netlify.toml`)
- Deploy: เชื่อม repo นี้กับ Netlify → push ครั้งใดก็ deploy อัตโนมัติ
